## Описание

YaMDB API предоставляет RESTful интерфейс для приложения сбора отзывов, позволяющий:
- добавлять и хранить сведения о произведениях
- составлять отзывы к произведениям
- отслеживать рейтинг проивзедений на основе отзывов
- комментировать отзывы
- Аутентифицироваться с использованием токенов

API соответствует спецификации OpenAPI 3.0 и имеет полную документацию в формате Redoc.

## Технологии

- Python
- Django
- Django REST Framework
- SQLite (для разработки)

## Установка

### 1. Клонирование репозитория
```bash
git clone <ваш-репозиторий>
cd api_yamdb
```

### 2. Создание виртуального окружения

Для Windows:
```bash
py -3.12 -m venv venv
venv\Scripts\activate
```

Для Linux/Mac:
```bash
python3.12 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка базы данных
```bash
python manage.py migrate
```

### 5. Создание суперпользователя (опционально)
```bash
python manage.py createsuperuser
```

### 6. Запуск сервера
```bash
python manage.py runserver
```
Сервер будет доступен по адресу: http://127.0.0.1:8000/

## Документация

После запуска проекта документация доступна по адресам:

http://127.0.0.1:8000/redoc/ - визуальная документация Redoc

http://127.0.0.1:8000/api/v1/ - корень API

## Примеры запросов

### Аутентификация

Регистрация нового пользователя:
```bash
curl -X POST http://localhost:8000/api/v1/auth/signup/ \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "username": "testuser"
  }'
```

Получение JWT-токена:
```bash
curl -X POST http://localhost:8000/api/v1/auth/token/ \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "confirmation_code": "123456"
  }'
```

## Отзывы

### Добавление отзыва на произведение:
```bash
curl -X POST http://localhost:8000/api/v1/titles/1/reviews/ \
  -H "Authorization: Bearer {ваш_токен}" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Отличный фильм с глубоким смыслом!",
    "score": 9
  }'
```

### Ответ
```json
{
  "id": 1,
  "text": "Отличный фильм с глубоким смыслом!",
  "author": "testuser",
  "score": 9,
  "pub_date": "2024-01-15T10:30:00Z"
}
```

## Импорт из CSV
Проект включает встроенную систему импорта данных, которая позволяет заполнить базу данных начальными данными из CSV файлов.

### Структура файлов
CSV файлы должны располагаться в директории static/data/. Проект ожидает следующие файлы:

```text
static/data/
├── category.csv        # Категории произведений
├── genre.csv           # Жанры
├── users.csv           # Пользователи
├── titles.csv          # Произведения
├── review.csv          # Отзывы
├── comments.csv        # Комментарии к отзывам
└── genre_title.csv     # Связи между произведениями и жанрами (ManyToMany)
```

### Запуск импорта
Для загрузки данных выполните команду:

```bash
python manage.py import_csv
```

### Пример вывода при успешном импорте:

### Особенности работы

#### Порядок импорта
Данные импортируются в определенном порядке, чтобы соблюсти целостность внешних ключей:

**Категории → Жанры → Пользователи → Произведения → Отзывы → Комментарии**

#### Обработка ошибок
* Система продолжает работу при ошибках в отдельных строках

* Выводится подробная информация об ошибках с указанием номера строки

* Транзакционная обработка обеспечивает целостность данных

## Структура API

Аутентификация
|Метод	|Endpoint	|Описание	|Права доступа |
|-------|-----------|-----------|--------------|
|POST	|/api/v1/auth/signup/	|Регистрация нового пользователя	|Доступно без токена |
|POST	|/api/v1/auth/token/	|Получение JWT-токена	|Доступно без токена |

Пользователи
|Метод	|Endpoint	|Описание	|Права доступа |
|-------|-----------|-----------|--------------|
|GET	|/api/v1/users/	|Получение списка всех пользователей	|Администратор |

|GET	|/api/v1/users/{username}/	|Получение пользователя по username	|Администратор |
|PATCH	|/api/v1/users/{username}/	|Изменение данных пользователя	|Администратор |
|DELETE	|/api/v1/users/{username}/	|Удаление пользователя	|Администратор |
|GET	|/api/v1/users/me/	|Получение данных своей учетной записи	|Любой авторизованный пользователь |
|PATCH	|/api/v1/users/me/	|Изменение данных своей учетной записи	|Любой авторизованный пользователь |

Категории
|Метод	|Endpoint	|Описание	|Права доступа |
|-------|-----------|-----------|--------------|
|GET	|/api/v1/categories/	|Получение списка всех категорий	|Доступно без токена |
|POST	|/api/v1/categories/	|Добавление новой категории	|Администратор |
|DELETE	|/api/v1/categories/{slug}/	|Удаление категории	|Администратор |

Жанры
|Метод	|Endpoint	|Описание	|Права доступа |
|-------|-----------|-----------|--------------|
|GET	|/api/v1/genres/	|Получение списка всех жанров	|Доступно без токена |

|DELETE	|/api/v1/genres/{slug}/	|Удаление жанра	|Администратор |

Произведения
|Метод	|Endpoint	|Описание	|Права доступа |
|-------|-----------|-----------|--------------|
|GET	|/api/v1/titles/	|Получение списка всех произведений	|Доступно без токена |
|POST	|/api/v1/titles/	|Добавление произведения	|Администратор |
|GET	|/api/v1/titles/{id}/	|Получение информации о произведении	|Доступно без токена |
